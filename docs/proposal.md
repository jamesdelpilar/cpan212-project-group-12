1. Task Tracker is an app that helps individuals or groups of people track their progress for a specific project with X amount of tasks/to-do "cards". The problem that task tracker solves is listing all the tasks that needs to be done and organizes them in a simplified way (e.g., To-Do, In-Progress, Done, etc.). Creating the ability of "writing" tasks allows the people involved in the project to quickly glance on the tasks and immediately work on the task without having to communicate with other members of the team.

2. Features:
- The user has the ability to create a "task card" for a project "to-do list"
- The user has the ability to create different categories and assign the "task card" to the created categories
- The user is able to assign member(s) of a project to a "task card"
- The user can colour-code "task cards"

3. An external API is not needed at the time of writing. Subject to change.

4. A project board has many tasks; a user writes/owns many project boards
